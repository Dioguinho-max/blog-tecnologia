O que é uma API?

Publicado em 02 de Agosto de 2026 • 5 minutos de leitura

O que significa API?

API significa Application Programming Interface. Ela é um conjunto de regras que permite que diferentes sistemas conversem entre si.

Como funciona?

Imagine um restaurante. Você faz um pedido ao garçom. O garçom leva o pedido para a cozinha. Depois ele retorna com a comida. A API funciona exatamente como esse garçom: ela recebe uma solicitação, envia ao servidor e devolve a resposta para quem fez o pedido.

Exemplos de APIs

  • API do GitHub
  • API do OpenAI
  • API do Google Maps
  • API do ViaCEP
  • API do CoinGecko

Conclusão

As APIs são fundamentais para a internet moderna. Graças a elas, aplicativos, sites e serviços conseguem compartilhar informações de forma rápida e segura.
